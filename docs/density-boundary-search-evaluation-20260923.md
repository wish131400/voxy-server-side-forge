# 密度边界搜索：水平格点的误差界收紧（2026-09-23）

问题：展示采样在间隔 4 的稀疏网格上，每列经常遍历多个高度格。`final_density` 的水平格点只需两枚垂直插值角点，但原来的误差保护使用插值子图的全局最大幅值。真实世界中，所选角点约为 -0.078125，而全局幅值导致区间扩大到约 -0.676..0.519；空格无法被证明，进入多层递归和逐高度求值。

改动：保留全局幅值 `< 1e100` 作为未选角点不会参与 NaN/溢出的安全门槛；实际区间扩张仅使用参与 Y 插值的两枚角点的最大绝对值。X/Z 的零权重仍保持原有插值顺序，若全局边界不可证明或端点非有限，则仍走原来的完整角点/逐点路径。未修改材质、液体、结构、回退或 Java 采样语义。

测试方法：同一份源码分别复制成基线/候选原生 crate，仅修改上述误差界；同编译设置独立 DLL；Java JNI 测试器分别以独立进程运行 5 轮，交替基线与候选顺序。单位为完整展示路径的每列中位耗时（µs），输入来自仓库的原版快照与地形模组快照。运行数据：`build/density-boundary-search-20260923/runs.json`（忽略目录）。各同场景全批输出校验和相同；45 对输出 TSV 逐字节一致。
